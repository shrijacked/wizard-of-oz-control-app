# Physical setup figure

`physical-setup-topdown.tex` is the editable, standalone TikZ source. The PDF is a vector export; the PNG is a review preview.

The layout follows IMG_0144.PNG and the author's clarifications: an opaque partition separates the researchers from the participant; a camera mounted above the partition covers the whole participant table; unused pieces occupy fixed, labelled pickup positions; the puzzle is assembled to the left of the drop spot; and the participant uses a laptop for the task display and questionnaire responses.

Table dimensions, spacing, camera placement along the partition, and pickup-position arrangement are schematic. Piece colours follow the project configuration; colour labels illustrate labelled positions and should be replaced if the physical labels differ. The robot symbol is an abstract arm, not a model-specific drawing.
